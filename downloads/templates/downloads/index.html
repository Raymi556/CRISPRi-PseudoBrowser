About This Browser

This browser provides interactive tools for exploring CRISPRi-seq screening data in Pseudomonas aeruginosa. The browser combines gene-level summaries, guide-level observations, pathway annotations, and mismatch-guide measurements across the available experimental conditions.

Choosing an export

Start with Gene annotation and Comparison manifest for identifiers and condition labels. Add Guide metadata for guide design context, Gene-condition summaries for compact screening results, or Guide observations when guide-level measurements are required. Use the filtered Mismatch observations or pathway records only for those focused analyses.

Dependencies

  • Python 3.11
  • Django 5.2
  • SQLite database
  • Plotly.js and DataTables
