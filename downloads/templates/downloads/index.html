About This Browser

This browser provides interactive tools for exploring CRISPRi-seq screening data in Pseudomonas aeruginosa. The browser combines gene-level summaries, guide-level observations, pathway annotations, and mismatch-guide measurements across the available experimental conditions.

Available Datasets

  • Gene annotation: gene identifiers, names, products, genomic features, and coordinates.
  • Comparison manifest: batches, comparison labels, and comparison classes used by the browser.
  • Guide metadata: guide sequences, guide types, model scores, and guide-level metadata.
  • Guide observations: guide-level effects and statistical measurements for each comparison.
  • Gene-condition summaries: median LFC, Stouffer p-values, and significance fields used by Condition and Compare.
  • Mismatch observations: perfect and mismatch guide measurements used by Mismatch Data.
  • COG and Gene Ontology records: pathway annotations used by the Pathway tab.

Dependencies

  • Python 3.11
  • Django 5.2
  • SQLite database
  • Plotly.js and DataTables
