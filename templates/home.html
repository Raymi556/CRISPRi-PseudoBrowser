CRISPRi-seq Data Browser

Interactive exploration of Pseudomonas aeruginosa CRISPRi screening data

Current Capabilities

Gene Browser

Visualize CRISPRi guide effects in P. aeruginosa genomic context with interactive plots. Search by gene name or PAO1 identifier, adjust genomic windows, and compare across experimental conditions.

Features:

  • Gene context visualization showing guide positions
  • Guide-level Log2 fold change plots
  • Multi-condition comparison
  • Customizable genomic window size
  • Interactive Plotly visualizations
  • CSV data export

Quick Start Guide

1

Navigate to Gene Browser

Click on the "Gene" tab in the navigation bar or use the link above.

2

Enter Gene Information

Type a gene name (e.g., dnaN) or PAO1 identifier (e.g., PA0003) in the search box.

3

Adjust Parameters

Set the genomic window size (default: 5000 bp) and select one or more experimental conditions to compare.

4

Generate Plots

Click "Generate Plots" to visualize the data. Interact with the plots and download results as CSV.
