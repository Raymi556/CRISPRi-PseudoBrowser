CRISPRi-seq Data Browser

Interactive exploration of Pseudomonas aeruginosa CRISPRi screening data

Move from a gene or guide-level observation to condition-wide hits, mismatch behavior, pathway context, and cross-condition comparisons in one place.

Starting Guide

01

Gene Browser

Search by gene name or PAO1 ID and inspect genomic context, guide positions, guide-level effects, and selected conditions.

  1. Choose a genomic window around the target and one or more experimental conditions.
  2. Generate plots to see the gene in context and compare guide-level log2 fold-change measurements.
  3. Click plot points to locate the corresponding guide in the data table; use the plot download control when you need a figure.
02

Guides Browser

Find perfect guides for a target gene and rank them using efficacy, off-target, abundance, and observed effect measures.

  1. Search for a gene name or PAO1 ID and select Find Guides.
  2. Compare Kawalek efficacy score, off-target count, abundance, median LFC, and maximum absolute LFC.
  3. Use conditions and batches as context before selecting a guide for follow-up work.
03

Mismatch Data

Explore graded mismatch-guide series for one gene and condition, then connect a plotted mismatch to its parent guide.

  1. Enter a gene name or PAO1 ID and choose an available condition.
  2. Generate the plot to compare perfect and mismatch guides across the series.
  3. Click a mismatch point to highlight its parent guide in the accompanying table.
04

Condition Browser

Scan a complete experimental condition with an interactive volcano plot and a filterable table of significant genes.

  1. Select a condition and generate its volcano plot.
  2. Read effect size against statistical significance, then click a gene point to find it in the significant-gene table.
  3. Filter the table for a focused list and download the rendered plot when documenting the result.
05

Pathway Analysis

Search COG or Gene Ontology terms, select linked genes, and send a focused gene set to Compare.

  1. Select COG or Gene Ontology and search by accession or term name.
  2. Choose a term to inspect its records and linked genes, then select the genes relevant to your question.
  3. Import the selected genes to the shared starred list so they can be compared in the Compare tab.
06

Gene Set Comparison

Review starred genes and render a clustered heatmap across available conditions to compare their response patterns.

  1. Review the starred genes and remove entries that do not belong in the set.
  2. Generate the heatmap to compare their responses across all available conditions.
  3. Inspect clustering for shared response patterns and download the heatmap for reporting.
07

Downloads

Export the database-backed records used by the browser, including annotations, guide measurements, summaries, mismatch observations, and pathway records.

  1. Choose an export whose description matches the browser question you are investigating.
  2. Use annotation and manifest files to identify records; use observation and summary files for measurements.
  3. Keep the comparison and identifier fields when joining exports to preserve condition and gene context.
